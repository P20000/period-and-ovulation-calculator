# Project Rules & Guidelines

- **Maximum 500 lines per file**: Keep every file concise, modular, and under 500 lines of code.
- **Modular OOP Architecture**: Encapsulate data models, storage, calculation logic, and UI components into separate modules.
- **Cross-Platform Compatibility**: Runtime detection of OS (Linux/Windows/macOS) and UI environment (GTK4/Libadwaita with Tkinter fallback).
- **Safe & Efficient Data Persistence**: Backward-compatible JSON storage, validation, and atomic writes.
